# ResConnect

ResConnect is a student-accommodation platform for George, South Africa.

The goal is to make it easier for students to find accommodation, understand their options and make informed decisions about where they stay.

## Technologies

- React – building the user interface
- JavaScript – application programming language
- Vite – development and build tool
- CSS – styling
- ESLint – code quality and error checking
- Git and GitHub – version control

## Getting Started

### Requirements

- Node.js
- npm
